# pyperscan

An opinionated Python binding for [Hyperscan](http://hyperscan.io) focusing on easy of
use and safety.

See [Usage](https://vlaci.github.io/pyperscan/usage/) to get started and [API Documentation](https://vlaci.github.io/pyperscan/api/) for a comprehensive
overview.
